# For non-Claude agents (Codex, Cursor, etc.)

Nothing auto-loads on your platform — read files yourself before acting.

**First run:** read `SEED.md` in full, then begin — it tells you how to grow a second brain shaped
to the person you're talking to. Its Gate 0 creates `BRAIN_CORE.md` and repoints this file at it.

**Returning? Check for the core, not the content.** If a filled `BRAIN_CORE.md` (or equivalent
core/identity doc) exists, read it first, then operate the brain — don't re-run setup. If the core
doc is missing or blank, setup is INCOMPLETE no matter how much content the repo holds: compile
what's already here into the core and resume `SEED.md`'s persistence gates.
